# Data Science, NLP & R Analytics

Notebooks Python e relatórios em R Markdown com projetos de Processamento de Linguagem Natural (NLP), classificação de textos com *Deep Learning* e análise exploratória de dados de redes sociais.

## Estrutura

- `notebooks/classificadores-texto-deep-learning.ipynb`: Fine-tuning de modelo BERT em português (`neuralmind/bert-large-portuguese-cased`) com Hugging Face `transformers` para classificação de textos.
- `notebooks/extracao-analise-dados-tiktok.ipynb`: Extração e análise exploratória de métricas de postagens do TikTok.
- `r-markdown/`: Listas e notas práticas em R Markdown (`ggplot2`, `tidyr`, manipulação e visualização de dados).
